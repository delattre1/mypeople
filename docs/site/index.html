Your coding agents, as a team.

MyPlow does not contain an agent loop. It runs Claude Code, Codex and Grok as a team, with one Boss, a board and plugins.

InstallRead the docs

The agents you already log in to, with a team around them.

Each agent stays the CLI you already use, in its own terminal. MyPlow adds what one session does not have: someone in charge, a place where the work lives, and ways in from outside.

One Boss, many engineers

One long-lived Boss plans, routes and verifies. Each engineer owns one card, in its own terminal. Any agent can run on a different backend, and mp revive resumes the exact session it had.

A board that holds the work

One card per piece of work. Engineers post plans, progress and proof on it. A comment you leave goes straight to the card's owner, word for word, and the Boss gets a copy.

Plugins connect it to the outside

A plugin is a folder with a script and a config file. iMessage, Discord, GitHub reviews and a live mic ship in the box. Ask your agent to connect a new one. It arrives switched off.

Each plugin shows what it tells the agent. Add your own text by hand or by asking your agent. It is read per message, so no restart. The plugin's own lines stay fixed.

Agents on another MyPlow

You generate a line. The other agent runs it. You grant it on the Access page. Then mp send reaches their agents, and each person's permission message is text you edit or ask your agent to change.

A pairing proves the MyPlow, not who owns it. The text tells an agent. Nothing enforces it.

Start from a terminal

Docker (recommended)

Needs Docker with Compose. Log in once, inside the container.

git clone https://github.com/delattre1/mypeople.git
cd mypeople
docker compose pull
docker compose run --rm --entrypoint claude mypeople auth login
MYPEOPLE_BACKEND=claude docker compose up -d

Native installer

Installs what is missing, logs in the backend you chose, starts the stack.

git clone https://github.com/delattre1/mypeople.git
cd mypeople
MYPEOPLE_BACKEND=claude ./install.sh

Then open http://localhost:9933 and add a card. Codex, Grok and uv are in the install guide.

What is not built

  • No QR code. A pairing line is text you pass on yourself.
  • No per-person proof of identity. A pairing proves the MyPlow, not who owns it. You grant by eye.
  • No enforcement. Permission text tells an agent. Nothing enforces it.
  • The agent-to-agent thread is an experiment. It records what mp send --card delivered.
